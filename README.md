# portfolio-site

Personal portfolio for Cody Hoang: a static site with a fixed sidebar on desktop and a single
scrolling column on phones, listing about, projects, and experience.

**Live:** https://codyhoang.vercel.app

## Why Astro

Astro renders everything to plain HTML and CSS at build time and ships no JavaScript unless a
page asks for it. A portfolio is static content, so that gives fast loads with very little to
break. The only client-side script (about 40 lines) highlights the current section and plays
the project demo videos on hover.

## Run it locally

Requires Node.js 22.12 or later.

```sh
npm install
npm run dev      # http://localhost:4321
npm run check    # type-check .astro and .ts files
npm run build    # static output in dist/
```

## Editing content

All text lives in [`src/data/site.ts`](src/data/site.ts): about paragraphs, projects,
experience, and links. Layout code doesn't need to change for content edits.

### Adding a project demo video

Project cards always show a still image. On desktop (a real mouse, and no
`prefers-reduced-motion`), a card with a video crossfades to it on hover or keyboard focus.
Phones never download the video: its sources aren't attached until the first hover.

1. Record 5 to 10 seconds, export muted, ideally under 2 MB. For example, with ffmpeg:
   ```sh
   ffmpeg -i raw.mov -an -vf "scale=1200:-2,fps=30" -c:v libvpx-vp9 -b:v 0 -crf 38 public/demos/NAME.webm
   ffmpeg -i raw.mov -an -vf "scale=1200:-2,fps=30" -c:v libx264 -crf 26 -movflags +faststart public/demos/NAME.mp4
   ```
2. Match the still image's aspect ratio, or the video is cropped to fit (`object-fit: cover`).
3. In `site.ts`, set `video: { webm: "/demos/NAME.webm", mp4: "/demos/NAME.mp4" }` on the project.

### Social preview image

`public/og.png` (1200x630) is generated by `npm run og` from [`scripts/make-og.mjs`](scripts/make-og.mjs).
Re-run it after changing the name or title.

## Deployment

Vercel builds every push: `main` goes to production, and each pull request gets a preview URL.
Absolute URLs (canonical link, social image) come from Vercel's `VERCEL_PROJECT_PRODUCTION_URL`;
set `SITE_URL` to override it, for example after adding a custom domain.

## Accessibility

Semantic landmarks and headings, a skip link, visible focus outlines, keyboard-reachable
everything, and text contrast above WCAG AA on the dark background. Motion respects
`prefers-reduced-motion`.
